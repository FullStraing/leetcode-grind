# Roadmap

Patterns in learning order. A pattern is "done" when at least 3
problems in it are solved, tested, and can be re-solved from a
blank page without hints.

| # | Pattern | Status |
|---|---------|--------|
| 1 | HashMap | Done — Two Sum, Valid Anagram, Group Anagrams, Contains Duplicate |
| 2 | Two Pointers | Done — Two Sum II, Valid Palindrome, Container With Most Water |
| 3 | Sliding Window | Done — Longest Substring Without Repeating Characters, Minimum Size Subarray Sum, Longest Repeating Character Replacement |
| 4 | Binary Search | Done — Binary Search, Search Insert Position, First Bad Version, Sqrt(x) |
| 5 | Stack | Done — Valid Parentheses, Min Stack, Evaluate RPN, Daily Temperatures, Asteroid Collision, Remove Adjacent Duplicates, Decode String, Backspace Compare, Simplify Path |
| 6 | Linked List | Planned |

| 8 | Graphs | Planned |
| 9 | Heap / Priority Queue | Planned |
| 10 | Backtracking | Planned |
| 11 | Dynamic Programming | Planned |
| 12 | Greedy | Planned |

## Daily rule

2 problems a day. Every solved problem lands here as a tested
Python module with the approach and complexity written out —
no solution is "done" until its test passes and it can be
explained out loud in under a minute.
